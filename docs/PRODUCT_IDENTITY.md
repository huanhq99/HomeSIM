# MacCellular：产品身份与品牌规范

## 产品定义

MacCellular 是一个面向个人自托管的蜂窝通信产品：实体 SIM 与 4G 模块常驻家中 Mac，
手机通过用户自己的公网入口使用电话、短信、来电提醒和通话录音。家庭 Mac 只主动
建立外连，不直接暴露 USB、AT、本地管理或家庭网络端口。公开仓库不记录维护者实际
使用的域名、服务器、账户、邮箱、API 标识或部署参数。

中英文产品名统一为 **MacCellular**，说明性副标题为 **Self-hosted calls and SMS
from a USB cellular modem**。用户可见界面不再使用
DJI、DJOneHub、VoHive 或“蜂窝网关”作为主品牌；硬件厂商和历史项目名称只在设备
诊断、来源说明及兼容文档中出现。

## 视觉系统

- 主色：深海军蓝 `#06101E`，用于沉浸式电话界面；
- 品牌色：珊瑚橙 `#FF765E`，用于主要操作和品牌字形；
- 状态色：薄荷绿 `#8EE7D3` / `#48D597`，用于连接和通话就绪；
- 图标：电话听筒、SIM 与蜂窝信号组合，不使用个人首字母或硬件厂商标志；
- 产品语气：先说用户能做什么，再在折叠区域提供诊断状态。

主图源为 `docs/brand/maccellular-icon-master.png`。PWA 的 SVG、192、512 和
Apple Touch Icon 是同一视觉系统的运行资产。

## 界面信息架构

1. **首页**：当前线路、在线/语音/短信状态、来电提醒和快捷入口；
2. **电话**：当前通话、拨号盘、DTMF、最近通话与未接来电；
3. **短信**：会话优先，新短信按需展开，并明确显示记录总数和会话数；
4. **录音**：时间与通话对象命名，显示手机/Mac 保存状态。

1.0 只连接一块模块，界面明确称“当前线路”。线路昵称目前保存在该 PWA 设备。公开
产品不宣传或暗示卡池、批量插卡、批量呼叫、第三方线路转售等能力；任何未来的多线路
研究都必须先重新评估产品目的、运营商条款与适用法律，不能视为 1.0 的自然扩展。

## 来源与所有权边界

仓库保留 DJOneHub/VoHive 的 Git 沿革、原作者声明和 PolyForm Noncommercial 许可。
USB/AT 管理基础和部分早期 macOS 能力来自这些历史工作；MacCellular 的产品架构、
公网 PWA、Cloudflare Access、WebRTC/TURN 语音、来电推送、短信持久化、录音、
迁移安装器、恢复状态机与产品交互，均在本仓库围绕实际需求独立设计和实现。

因此准确表述是：“MacCellular 是自主设计的自托管电话产品，并在早期设备访问基础上
持续演进。”不能表述为“所有代码从未参考其他项目”，也不能删除原作者声明或擅自
更换整个仓库的许可。

## 兼容名策略

以下名称暂时保留，不代表对外品牌：

- Go module `github.com/iniwex5/vohive`；
- `cmd/djonehub-macos` 与已有二进制名；
- API 中已部署的稳定字段和路径。

对外 App 名称、bundle ID、LaunchAgent label 和全新安装的数据目录已经统一为
MacCellular；旧 `DJOneHub` 数据目录仅作为私人测试版迁移源读取。

它们只应在一次有迁移、回滚和数据兼容方案的版本中统一调整，不能为了表面改名破坏
现有电话、短信、录音或后台服务。
