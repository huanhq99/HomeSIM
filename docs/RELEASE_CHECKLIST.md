# MacCellular 1.0 发布检查表

目标版本：`1.0.0`。当前候选：`1.0.0-rc.4`。当前允许公开源码仓库和 RC
预发布；本文件保留的未完成项仍阻止将其标记为 `v1.0.0` 正式版或生产就绪版本。

当前结论：源码、安装包、普通用户向导和静态/自动化回归已达到 RC 标准。正式
`v1.0.0` 前还需完成本表中未勾选的录音实机复验与整机耐久验证；发布动作保持未执行。

## 私有发布候选

公开前先导出不包含本机运行数据和旧 Git 历史的干净源码树：

```bash
./scripts/stage-public-source.sh
```

候选目录位于 `local/public-release/`，不会进入 Git。所有复核和测试应直接在该候选目录中执行；不要把当前私人仓库的历史直接公开。
