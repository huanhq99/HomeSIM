# 许可证说明

MacCellular 1.0 使用仓库根目录的 **PolyForm Noncommercial 1.0.0**，并保留
VoHive 的 required notice。它允许个人研究、学习、实验及其他许可证列明的非商业
用途，但不是 OSI 认可的开源许可证。第三方组件继续适用各自许可证。

## 为什么 1.0 不直接改成 AGPL-3.0

1. 仓库包含从 VoHive/DJOneHub 演进而来的代码。我们无权单方面把其他版权人的代码
   整体改用另一份许可证；变更需要先确认完整版权链并取得必要许可。
2. AGPL-3.0 解决的是“修改后作为网络服务运行但不提供源码”的问题。它要求网络用户
   能取得相应源码，但仍允许商业使用、收费和再分发，不能用来禁止商业化。
3. 当前目标是公开源码供个人使用，同时避免未经许可的商业产品化；现有非商业许可
   比 AGPL 更接近这个目标。

## 两个常见误解

- MIT 许可证允许商业使用、修改和再分发，但并不是“连出处都可以不标”。分发副本或
  重要部分时仍须保留原版权声明和 MIT 许可文本。
- AGPL 是网络场景的强 copyleft：修改后的程序向网络用户提供服务时，需要向这些用户
  提供相应源码。它并不禁止商业使用、收费、销售或再分发，因此不能替代非商业限制。

## 未来可以怎样调整

如果后续取得上游版权人的明确授权，并完成独立代码与继承代码的边界整理，可以再选：

- 整体继续使用 PolyForm Noncommercial；
- 对完全独立且版权清晰的组件采用 AGPL-3.0-or-later；
- 在版权人一致同意后，为整个项目采用 AGPL 或双重许可。

任何调整都应逐文件保留版权声明和第三方许可证，不能只替换根目录 `LICENSE` 文件。
本说明是项目维护决策，不构成法律意见；正式重许可前应由熟悉软件版权的律师确认。
